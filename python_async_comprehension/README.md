# Python - Async Comprehension

This project covers asynchronous comprehension concepts in Python, including asynchronous generators, yield expressions, and type-annotated asynchronous iterators as part of the Holberton School backend curriculum.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Interpreted/compiled on Ubuntu 20.04 LTS using Python 3.8
- All files end with a new line and must be executable
- Code follows `pycodestyle` (version 2.5.x)
- All functions and coroutines must be type-annotated
- All modules and functions include proper documentation
